# Jornada da Lógica 🚀

**Seu Start na Programação**

Bem-vindo ao repositório da **Jornada da Lógica**, uma aplicação web interativa desenvolvida para introduzir conceitos fundamentais de lógica de programação de forma lúdica e gamificada. Este projeto é ideal para iniciantes que desejam entender como os computadores "pensam" sem precisar escrever linhas complexas de código logo de cara.

## 📋 Sobre o Projeto

A **Jornada da Lógica** é uma Single Page Application (SPA) que utiliza metáforas do mundo real e jogos simples para explicar:
*   Algoritmos e Sequenciamento (O Robô Cego)
*   Lógica Booleana (Modo Detetive)
*   Depuração de Código (Debug)
*   Gamificação de conceitos técnicos

## ✨ Funcionalidades

### 1. 🤖 Missão: Programe o Robô
Um jogo interativo onde o usuário deve guiar um robô até a bandeira de chegada utilizando uma sequência de comandos (Frente, Virar Esquerda, Virar Direita).
*   Demonstração prática de algoritmos sequenciais.
*   Visualização de execução passo a passo.
*   Feedback visual de erros (colisões).

### 2. 🕵️ Modo Detetive
Explicação visual dos operadores lógicos (AND, OR, NOT) e um **Mini-Desafio Interativo** onde o usuário precisa descobrir uma "senha" baseada em condições lógicas.

### 3. 🎮 Gamificação e Pílulas de Conhecimento
Cards informativos que relacionam conceitos de programação com jogos populares (Minecraft, Among Us) e ferramentas de aprendizado (Scratch, Python).

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias web padrão, sem dependência de frameworks externos, garantindo leveza e facilidade de estudo:

*   **HTML5**: Estrutura semântica.
*   **CSS3**: Estilização moderna com variáveis (CSS Variables), Flexbox, Grid Layout e animações (Glow effects).
*   **JavaScript (Vanilla)**: Lógica dos jogos e interatividade do DOM.

## 🚀 Como Executar

Não é necessário instalar nada! Como é um projeto estático:

1.  Faça o download ou clone este repositório.
2.  Navegue até a pasta do projeto.
3.  Abra o arquivo `index.html` em seu navegador favorito (Chrome, Firefox, Edge, etc.).

## 🎨 Design

O projeto apresenta um tema "Dark/Neon", inspirado em estética Cyberpunk/Gamer, utilizando:
*   Fontes: 'Orbitron' (Títulos) e 'Inter' (Corpo).
*   Paleta de Cores: Roxo Neon (#bd00ff), Ciano (#00f3ff) e Verde (#00ff66) sobre fundo escuro.
